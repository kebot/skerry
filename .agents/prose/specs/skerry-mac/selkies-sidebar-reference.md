# Selkies web sidebar source reference

The screenshot shows the **Sidebar** layout of the Selkies web dashboard with its sections collapsed. This dashboard runs alongside the remote picture inside a Selkies session. SealSkin’s outer web launcher owns application and session selection. The source links below pin Selkies commit `715df7cdea9c6c21ae339f93f194f718a879dc41`. The screenshot’s exact build is unknown. At this revision, fullscreen and gaming mode sit in a separate row below the header, while the screenshot places them beside the theme and layout controls. [Web client architecture and layouts](https://github.com/selkies-project/selkies/blob/715df7cdea9c6c21ae339f93f194f718a879dc41/docs/components/web-client.md) · [Sidebar source](https://github.com/selkies-project/selkies/blob/715df7cdea9c6c21ae339f93f194f718a879dc41/web/selkies-dashboard/src/layouts/sidebar/index.tsx#L138)

## From a UI action to the stream

- **Playback and devices.** A tile calls a method on `DashboardProvider`. The video, audio, microphone, and webcam methods post `pipelineControl` to the streaming core. The core translates it to the transport command, such as `START_VIDEO` or `STOP_VIDEO`. The dashboard reads pipeline state updates back from the core. Gamepad input uses its own control. [Dashboard state](https://github.com/selkies-project/selkies/blob/715df7cdea9c6c21ae339f93f194f718a879dc41/web/selkies-dashboard/src/state/dashboard.tsx#L508) · [WebSocket control handling](https://github.com/selkies-project/selkies/blob/715df7cdea9c6c21ae339f93f194f718a879dc41/web/selkies-web-core/selkies-ws-core.ts#L5681)
- **Video settings.** `useStreamSettings()` reads `serverSettings`, resolves bounds and locks, and forwards changed values to the core. The WebSocket core formats the values as `SETTINGS,{json}`. [Settings state](https://github.com/selkies-project/selkies/blob/715df7cdea9c6c21ae339f93f194f718a879dc41/web/selkies-dashboard/src/state/settings.ts#L196) · [WebSocket settings sender](https://github.com/selkies-project/selkies/blob/715df7cdea9c6c21ae339f93f194f718a879dc41/web/selkies-web-core/selkies-ws-core.ts#L3738)
- **Resolution and pointer geometry.** `setManualResolution` and `resetResolutionToWindow` are distinct from local scaling and anti-aliasing. The core handles remote size changes. `Input._windowMath()` derives scale and letterbox offsets for mouse input from the displayed element. [Resolution handlers](https://github.com/selkies-project/selkies/blob/715df7cdea9c6c21ae339f93f194f718a879dc41/web/selkies-web-core/selkies-ws-core.ts#L5540) · [Pointer mapping](https://github.com/selkies-project/selkies/blob/715df7cdea9c6c21ae339f93f194f718a879dc41/web/selkies-web-core/lib/input.ts#L5392)
