# Add a stream diagnostics view

Show client FPS, received bitrate, stream resolution, current transport/codec, decode time, and dropped frames. Show server encoder data and RTT when available, and distinguish server-reported values from client measurements. Capture a repeatable memory and latency baseline at fixed resolutions before adding more codecs.
