# Find and organize applications

Add search, app icons, recent apps, favorites, and hidden apps. Save per-app launch preferences locally. Evaluate pinned app links and reuse of a running session with matching app and storage. Validate app IDs, links, and capability filters. Keep visual customization such as wallpaper and branding lower priority.
