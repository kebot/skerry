# Show account limits and recover expired or dormant access

Show the signed-in account, effective capabilities, and usage limits where the API exposes them. For dormant keys, offer the documented browser wake flow and retry. Prompt for a replacement on expiry or revocation. Leave key creation and revocation in the authenticated web app. Evaluate connection-config import separately because exported files may contain a credential.
