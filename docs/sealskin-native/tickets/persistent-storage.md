# Manage SealSkin homes, shared files, and public links

Use SealSkin storage APIs for home directories and shared files. Support browse/search, new folders, uploads/downloads, and opening a stored file without uploading it again. Add public share creation, password/expiry, and revocation only where permitted. Verify background deletion and no-persistence accounts. Session-level transfer remains covered by the [Selkies file transfer ticket](file-transfers.md).
