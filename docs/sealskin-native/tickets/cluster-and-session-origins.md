# Handle cluster placement and isolated session URLs

Offer Automatic, pool, or node placement where available and show home placement and remaining allowance. Evaluate permitted storage moves. Validate address resolution, trusted session origins, and token handoff before supporting deployments with per-session origins. Keep application keys on the control-plane origin. Test single-node, clustered, and session-isolated deployments separately.
