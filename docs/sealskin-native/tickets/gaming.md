# Add gaming controls

Add relative pointer capture with an escape shortcut, then physical gamepad forwarding with slot and rumble support. Add soft keys or custom chords where they solve a Mac keyboard limitation. Touch-only trackpad emulation and virtual touch gamepads can wait for a touch client.
