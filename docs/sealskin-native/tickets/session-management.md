# Manage running sessions

Use server thumbnails to identify sessions and add Send File and Stop. Keep Stop distinct from Disconnect. Explain that stopping ends the remote process and removes cleanroom data. Refresh after external changes and verify that the client can resume and disconnect without stopping the session.
